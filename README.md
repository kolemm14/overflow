# Extensions et plugins After Effects

Ce depot public regroupe les plugins natifs FX Pro pour After Effects 2020 et l'extension CEP OVER FLOW pour After Effects CC 2018-2020.

## OVER FLOW pour AE CC 2018-2020

L'extension CEP complete se trouve dans `extensions/Overflow-AE2018/`. Pour l'installer, copiez ce dossier dans `%APPDATA%/Adobe/CEP/extensions/`, fermez puis relancez After Effects et ouvrez le panneau **Window > Extensions > OVER FLOW**. La licence MIT est incluse dans le dossier.

Elle propose notamment des courbes Bezier, des outils d'interpolation et de manipulation de calques. Aucun framework ou composant commercial tiers n'est inclus.

## FX Pro pour After Effects 2020

Les plugins sont fournis dans `plugins/FX Pro/` :

- `FXPro_AuraGlow.aex`
- `FXPro_Impact.aex`
- `FXPro_MotionBlur.aex`
- `FXPro_RGBSplit.aex`
- `FXPro_Shake.aex`
- `FXPro_SmoothTime.aex`
- `FXPro_ZoomWhip.aex`

Copiez ce dossier dans le dossier `Plug-ins` d'After Effects 2020. Les presets `.ffx`, installateurs, extensions retirees et donnees personnelles de migration ne sont pas inclus.

Ces plugins sont des binaires Windows compiles. Le depot etant public, leur telechargement est accessible a tous.
