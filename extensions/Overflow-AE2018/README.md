# OVER FLOW 0.2

Extension CEP légère et indépendante pour After Effects CC 2018–2020.

## Installation sous Windows

Fermez After Effects, puis double-cliquez sur `INSTALL_OVERFLOW.cmd`. Le script installe l'extension dans le dossier CEP de l'utilisateur sans droits administrateur. Relancez After Effects et ouvrez **Window > Extensions > OVER FLOW**.

- Courbes Bézier interactives, presets, application entrée/sortie, lecture et outils d’interpolation.
- Text Exploder (caractères, mots, lignes).
- Alignement, point d’ancrage 3×3, création de calques.
- Presets natifs simples, bascule d’effets et motion blur, renommage par lot.
- Aucun framework, aucune télémétrie, aucun composant commercial tiers.

Le module Audio est volontairement réservé à la phase 3.
